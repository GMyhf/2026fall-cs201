## 4 重要注意事项

建议在开课前完成 **LeetCode 热题 100**。

*   **预习范围**：可暂不包含“链表”（14题）和“二叉树”（15题）。
*   **目标**：通过刷题消除编程语言隔阂，确保能跟上数算课程的教学节奏。
