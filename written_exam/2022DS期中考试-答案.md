## 二、辨析与简答（30 分）

### 1. 顺序栈 vs 链式栈（3 分）

- **时间**：两者 push / pop / top 都是 O(1)。顺序栈只移动栈顶下标，常数更小、局部性好；
  链式栈每次 push/pop 要申请/释放结点，常数较大。顺序栈满时若要扩容，需整体搬移（单次 O(n)，
  按倍增扩容摊还仍为 O(1)）；不扩容则有上溢问题。
- **空间**：顺序栈要预先分配定长数组，开大了浪费、开小了会溢出，但每个元素没有额外开销；
  链式栈按需分配、长度不受限（只受内存限制），但每个元素多一个指针域的结构性开销。

### 2. 字符串 "1212123"

**（1）** 所有不同非空子串，按 ASCII 字典序（'1' < '2' < '3'，前缀排在前面）共 18 个：

```text

```

**（2）** 优化后的 next 特征向量：

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| P[i] | 1 | 2 | 1 | 2 | 1 | 2 | 3 |
| 未优化 next | −1 | 0 | 0 | 1 | 2 | 3 | 4 |
| **优化 next** | **−1** | **0** | **−1** | **0** | **−1** | **0** | **4** |

优化规则：若 `P[i] == P[next[i]]`，则 `next[i] = next[next[i]]`（用已优化的值）。
i=2,4 处 P[i]='1'=P[0]，取 next[0]=−1；i=3,5 处 P[i]='2'=P[1]，取 next[1]=0；
i=6 处 P[6]='3'≠P[4]='1'，保持 4。

## 四、算法设计与实现（30 分）

### 1. 两个队列模拟栈（10 分）

**思路**：维持不变式「栈的全部元素都在 A 中，且 A 的队首就是栈顶，B 平时为空」。
于是 top / pop / empty 直接作用于 A 的队首；push 时借 B 把新元素调到 A 的最前面。
只用常数个临时变量，额外空间 O(1)（元素本身存在 A、B 里）。

```text
push(x):
    B.push_back(x)                    // 新元素先进 B，成为 B 的队首
    while not A.empty():              // 把 A 的元素依次接在 x 后面（相对顺序不变）
        B.push_back(A.front()); A.pop_front()
    while not B.empty():              // 再整体倒回 A，恢复「B 为空」的不变式
        A.push_back(B.front()); B.pop_front()
    // 此时 A = x, 原栈顶, ..., 原栈底

top():   return A.front()             // 队首即栈顶
pop():   A.pop_front()
empty(): return A.empty()
```

时间：push O(n)，其余 O(1)。（第二个 while 是为了不使用「交换 A、B」这种题目未提供的操作。）

已对拍：依次 push 0..4 后连续 top/pop 得到 4 3 2 1 0。

### 2. 判断 AA 型子串，返回第一次出现的起始下标（10 分）

**思路**：枚举半长 L = 1 … ⌊n/2⌋。长度 2L 的子串 `S[i..i+2L-1]` 是 AA 串，
当且仅当对 j = i … i+L−1 都有 `S[j] == S[j+L]`。所以对固定的 L，
扫描 j 并维护「以 j 结尾、连续满足 `S[j]==S[j+L]` 的长度」run；
run 首次达到 L 时，`j−L+1` 就是该半长下最早的 AA 起点。
所有 L 的最早起点取最小值即为答案。

```cpp
// 返回 S 中第一个 AA 型子串的起始下标；没有则返回 -1
int firstSquare(const string& s) {
    int n = s.size(), best = -1;
    for (int L = 1; 2 * L <= n; ++L) {          // 枚举 A 的长度
        int run = 0;                            // 连续满足 s[j]==s[j+L] 的个数
        for (int j = 0; j + L < n; ++j) {
            run = (s[j] == s[j + L]) ? run + 1 : 0;
            if (run >= L) {                     // s[j-L+1 .. j] 与其后 L 个字符相同
                int start = j - L + 1;
                if (best < 0 || start < best) best = start;
                break;                          // 该 L 下最早的起点已找到
            }
        }
    }
    return best;
}
```

**正确性**：run ≥ L ⇔ `S[j−L+1..j] == S[j+1..j+L]`，即以 `j−L+1` 起、长 2L 的子串是 AA 串；
j 从小到大扫描，run 第一次到达 L 的位置给出该 L 下最小的起点。
注意不能在第一个找到 AA 的 L 上直接返回——较大的 L 可能起点更靠前
（例如 "abcabcaa"：L=1 起点 6，L=3 起点 0），所以要对所有 L 取最小。

**复杂度**：每个 L 扫描 O(n)，共 n/2 个 L，时间 **O(n²)**，额外空间 O(1)。

已对拍：与 O(n³) 暴力解在 20 万个随机串（字母表 {a,b,c}，长度 0–11）上结果一致；`"dabcabc"` 返回 1。

### 3. 二叉树中和为 targetSum 的向下路径数（10 分）

> M437.路径总和 III
>
> https://leetcode.cn/problems/path-sum-iii/

**思路（前缀和 + 哈希表 + 回溯）**：沿根到当前结点的路径，记前缀和 cur。
一条以当前结点为终点的向下路径，和等于 target，当且仅当路径上方某个祖先位置的前缀和等于
cur − target。DFS 时用哈希表 cnt 记录「当前根到此路径上」各前缀和出现的次数，
进入结点时累加答案并登记 cur，回溯时撤销登记（保证只统计祖先，不跨分支）。

```cpp
int dfs(Node* t, long long cur, long long target, unordered_map<long long,int>& cnt) {
    if (!t) return 0;
    cur += t->val;                                  // 根到 t 的前缀和
    int res = cnt.count(cur - target) ? cnt[cur - target] : 0;  // 以 t 为终点的路径数
    ++cnt[cur];                                     // 登记，供子孙使用
    res += dfs(t->left, cur, target, cnt) + dfs(t->right, cur, target, cnt);
    --cnt[cur];                                     // 回溯：离开 t 的子树后撤销
    return res;
}
int pathSum(Node* root, int target) {
    unordered_map<long long,int> cnt;
    cnt[0] = 1;                                     // 空前缀，对应从根开始的路径
    return dfs(root, 0, target, cnt);
}
```

**复杂度**：每个结点访问一次、哈希操作期望 O(1)，时间期望 **O(n)**；
空间为哈希表与递归栈 O(h)（h 为树高，最坏 O(n)）。
（朴素做法：对每个结点为起点向下 DFS 统计，时间 O(n·h)，最坏 O(n²)，也可接受。）

已验证：题目示例（target = 8）输出 3。

## 五、分析证明题（10 分）

设 T 为非空 k 叉树（k ≥ 2），每个非叶结点恰有 k 个孩子。

**（1）** 设结点总数为 n，叶子数为 n₀。除根外每个结点恰有一条边连向父结点，故边数 = n − 1；
又每个非叶结点贡献 k 条边，故边数 = km。于是 n = km + 1，

　　**n₀ = n − m = (k − 1)m + 1**。

**（2）** 高度为 h（独根树高 1）。

- **最多**：每层都排满，第 i 层（i = 1…h）有 k^(i−1) 个结点，
  总数 = 1 + k + … + k^(h−1) = **(k^h − 1)/(k − 1)**。
- **最少**：前 h−1 层每层只有一个非叶结点（其余 k−1 个孩子都是叶子），高度才能达到 h 且结点最少。
  非叶结点数 m = h − 1，由（1）n = km + 1 = **k(h − 1) + 1**。
  论证：高为 h 的树中第 1…h−1 层每层至少有一个非叶结点（否则下一层不存在），故 m ≥ h − 1，
  而 n = km + 1 随 m 单调增，所以 n ≥ k(h−1) + 1，且上述构造取到等号。
