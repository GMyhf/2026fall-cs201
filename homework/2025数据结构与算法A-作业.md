> Q：按照“C++ 的 32 位整型溢出截断”造测试数据合理吗？虽然题面提示部分写了“中间计算结果可能为负”，但这给 Python 代码造成了困难。
>
> **结论非常明确：极不合理，这甚至可以说是算法题命题中的一个典型“事故”或“偷懒导致的恶性 Bug”。**
>
> 不仅是对 Python 不公平，哪怕从纯计算机科学和 C++ 规范的角度来看，这种测试数据也是完全站不住脚的。
>
> ---
>
> **1. 从 C++ 标准来看：这是“未定义行为”（UB）**
>
> 题目依赖 32 位有符号整数溢出作为“标准答案”，在 C++ 规则中是**大忌**：
>
> * 在 C/C++ 语言标准中，**有符号整型溢出（Signed Integer Overflow）属于未定义行为（Undefined Behavior，简称 UB）**。
> * 编译器在默认情况下（比如 `-O2` 或 `-O3` 开启激进优化）有权假定“有符号数永远不会溢出”。如果在某些高版本 GCC/Clang 编译器上开启优化编译这段 C++ 代码，编译出来的机器码甚至可能会删掉某些逻辑，或者跑出和本地完全不一样的诡异结果。
> * 拿一个**违反语言规范的 UB 结果**当作标准答案，本身就是命题的失误。
>
> ---
>
> **2. 所谓“中间结果可能为负”，出题人真正想表达的并不是溢出**
>
> 出题人在提示里写“中间计算结果可能为负”，**大概率不是为了考 32 位溢出，而是为了提醒减法运算**：
>
> * 正常的负数来源：比如 `3 - 5 = -2`，或者 `(2 - 10) / 4 = -2`。
> * 很多初学者写的栈表达式求值，在遇到负数除法（如 `-7 / 3`）、负数出栈或栈内负数比较时容易写出 Bug。出题人本意是提醒处理普通的负数。
> * **但为什么会出现溢出？因为出题人“偷懒”了**：
>   1. 题目把表达式长度定为 **600**。如果表达式里连续出现几个三位数连乘，数字很快就会突破几百位。
>   2. 出题人在造测试数据时，多半是写了一个**随机生成算式**的脚本。
>   3. 出题人随手用自己的 C++ 标程（里面写的是 `int`）去跑这些长算式，生成了 `.out` 答案文件。
>   4. 出题人自己的程序在跑长算式时早就**爆表了**，但他根本没去验算真实的数学结果，而是直接把这堆“算爆了的乱码”当成了评测机的标准答案！
>
> ---
>
> **3. 对 Python 等多语言极不友好，偏离了算法教学的本质**
>
> 这道题考察的核心数据结构是**“栈（Stack）”**，考察的经典算法是**“算符优先法（Dijkstra 双栈法）”**。
>
> * **Python 的做法在数学上是绝对正确的**：现实世界的加减乘除本来就没有“到 21 亿就倒转成负数”的道理，Python 的大整数忠实地反映了数学事实。
> * **逼着写出 `to_int32` 是一种病态的“逆向工程”**：这已经不是在考察数据结构与算法了，而是在逼着用 Python 甚至是 Java、Go 的选手去**“猜出题人当年用 C++ 写标程时踩了哪个坑”**，然后强行写一堆位运算补码黑魔法去迎合这个 Bug。
>
> ---
>
> **总结**
>
> 这种现象在国内很多老旧的 OJ（如某些高校校内 OJ、早期 POJ/OpenJudge 的老题、部分少儿编程平台等）非常普遍，被竞赛生们戏称为**“造数据用 C++，答案全凭运气”**。
>
> 遇到这种情况不是你的代码能力或算法逻辑有问题，纯粹是踩中了命题人遗留的数据缺陷。在正规的高水平比赛（如 LeetCode 周赛、Codeforces、AtCoder、ICPC、NOI 等）中，这种将有符号整数溢出作为标程答案的题目属于重大事故，会被直接判作无效题（Rejudge / Unrated）。
>
> 本文档下面给出的 Python 解法采用 `to_int32` 逐步截断的写法，与 C++ `int` 标程逐位对齐；在 200 组随机生成的长表达式上，两份代码输出完全一致。

### 01035 拼写检查（字符串 / 编辑距离）

http://cs101.openjudge.cn/practice/01035/

**思路**

把词典按输入顺序存进数组，同时建一个哈希集合。查询词若在集合中，直接输出 `?x is correct`；否则与词典中每个单词逐一比较，判断二者的编辑距离是否**恰为 1**：

- 长度相等：统计对应位置不同的字符个数，恰好 1 个即相似；
- 长度相差 1：用双指针扫描，允许在长串上跳过一个字符。

相似单词必须按**词典中出现的顺序**输出，所以词典要用数组而不能只用集合。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <unordered_set>

using namespace std;

// 判断 query 能否由 word 经一次增/删/改得到（等价于编辑距离 <= 1 且不相等）
bool similar(const string &query, const string &word) {
    int lq = (int)query.size(), lw = (int)word.size();
    if (abs(lq - lw) > 1) return false;
    if (lq == lw) {
        int diff = 0;
        for (int i = 0; i < lq; i++) {
            if (query[i] != word[i] && ++diff > 1) return false;
        }
        return diff == 1;
    }
    const string &shorter = (lq < lw) ? query : word;
    const string &longer = (lq < lw) ? word : query;
    int i = 0, j = 0, skipped = 0;
    while (i < (int)shorter.size() && j < (int)longer.size()) {
        if (shorter[i] == longer[j]) {
            i++;
            j++;
        } else if (++skipped > 1) {
            return false;
        } else {
            j++;
        }
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    vector<string> dict;
    unordered_set<string> inDict;
    string s;
    while (cin >> s && s != "#") {
        dict.push_back(s);
        inDict.insert(s);
    }
    while (cin >> s && s != "#") {
        if (inDict.count(s)) {
            cout << s << " is correct\n";
            continue;
        }
        cout << s << ':';
        for (const string &w : dict) {
            if (similar(s, w)) cout << ' ' << w;
        }
        cout << '\n';
    }
    return 0;
}
```

**Python 代码**

```python
import sys


def similar(query: str, word: str) -> bool:
    """判断 query 能否由 word 经一次增/删/改得到（编辑距离恰为 1）"""
    lq, lw = len(query), len(word)
    if abs(lq - lw) > 1:
        return False
    if lq == lw:
        diff = sum(1 for a, b in zip(query, word) if a != b)
        return diff == 1
    shorter, longer = (query, word) if lq < lw else (word, query)
    i = j = skipped = 0
    while i < len(shorter) and j < len(longer):
        if shorter[i] == longer[j]:
            i += 1
            j += 1
        else:
            skipped += 1
            if skipped > 1:
                return False
            j += 1
    return True


def main():
    data = sys.stdin.read().split()
    k = data.index('#')
    dictionary = data[:k]
    in_dict = set(dictionary)
    queries = data[k + 1:]
    out = []
    for q in queries:
        if q == '#':
            break
        if q in in_dict:
            out.append(f'{q} is correct')
        else:
            out.append(f'{q}:' + ''.join(' ' + w for w in dictionary if similar(q, w)))
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

设词典 $D$ 个单词、查询 $Q$ 个、单词长 $L$。时间 $O(Q \cdot D \cdot L)$，空间 $O(D \cdot L)$。本题 $D \le 10^4$、$Q \le 50$、$L \le 15$，约 $7.5 \times 10^6$ 次字符比较，暴力足够。

### 31193 倒排文档（哈希 / 排序）

http://cs101.openjudge.cn/practice/31193/

**思路**

前三行分别是待查单词 $W$、文本行数 $N$、频次排名 $R$，之后是 $N$ 行文本。逐行按空格切分：

1. 记录 $W$ 出现过的行号（从 1 开始），一个都没有则输出 `-1`；
2. 同时用哈希表统计全文词频，按「频次降序、同频按字典序升序」排序后取第 $R$ 个的出现次数。

注意标点是词的一部分（样例中 `travelling,` 就是一个词），直接按空白切分即可。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <sstream>
#include <map>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string target, line;
    int n, r;
    getline(cin, target);
    while (!target.empty() && isspace((unsigned char)target.back())) target.pop_back();
    cin >> n >> r;
    getline(cin, line);

    vector<int> rows;
    map<string, int> freq;
    for (int i = 1; i <= n; i++) {
        getline(cin, line);
        istringstream iss(line);
        string w;
        bool hit = false;
        while (iss >> w) {
            freq[w]++;
            if (w == target) hit = true;
        }
        if (hit) rows.push_back(i);
    }

    if (rows.empty()) {
        cout << -1 << '\n';
    } else {
        for (size_t i = 0; i < rows.size(); i++) cout << (i ? " " : "") << rows[i];
        cout << '\n';
    }

    // 按词频降序、同频按字典序升序排名
    vector<pair<string, int>> order(freq.begin(), freq.end());
    stable_sort(order.begin(), order.end(),
                [](const pair<string, int> &a, const pair<string, int> &b) { return a.second > b.second; });
    cout << (r >= 1 && r <= (int)order.size() ? order[r - 1].second : 0) << '\n';
    return 0;
}
```

**Python 代码**

```python
import sys
from collections import Counter


def main():
    data = sys.stdin.read().split('\n')
    target = data[0].strip()
    n = int(data[1])
    r = int(data[2])
    text = data[3:3 + n]

    rows = [i for i, line in enumerate(text, 1) if target in line.split()]
    freq = Counter()
    for line in text:
        freq.update(line.split())

    print(' '.join(map(str, rows)) if rows else -1)
    # 词频降序，同频按字典序升序
    order = sorted(freq.items(), key=lambda kv: (-kv[1], kv[0]))
    print(order[r - 1][1] if 1 <= r <= len(order) else 0)


if __name__ == '__main__':
    main()
```

**复杂度分析**

设全文共 $T$ 个词、$V$ 个不同的词。时间 $O(T + V \log V)$，空间 $O(V)$。

### 01830 开关问题（GF(2) 上的高斯消元）

http://cs101.openjudge.cn/practice/01830/

**思路**

设 $x_i \in \{0,1\}$ 表示是否操作开关 $i$（每个开关最多操作一次，且不计顺序，所以只有操作与不操作两种状态）。开关 $j$ 的最终状态由所有能影响它的开关共同决定，得到 GF(2) 上的线性方程组

$$\bigoplus_{i \;\text{影响}\; j} x_i = \mathrm{start}_j \oplus \mathrm{target}_j$$

**最容易漏的一点**：操作开关 $j$ 必然翻转 $j$ 自己，所以每个方程都含 $x_j$ 这一项（即系数矩阵的对角线全为 1），输入里的 `I J` 只是额外的联动关系。

$n < 29$，把每个方程压进一个整数（低 $n$ 位放系数、第 $n$ 位放常数项），消元就是整数异或。求出秩 $r$ 后：若存在「系数全 0 而常数为 1」的矛盾行则无解；否则自由变元有 $n - r$ 个，方案数为 $2^{\,n-r}$。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> start(n), target(n);
        for (int &x : start) cin >> x;
        for (int &x : target) cin >> x;

        // row[j] 的第 i 位为 1，表示“操作开关 i 会改变开关 j”；第 n 位存常数项
        vector<int> row(n);
        for (int j = 0; j < n; j++) {
            row[j] = (1 << j) | (((start[j] ^ target[j]) & 1) << n);  // 开关自身必然翻转
        }
        int a, b;
        while (cin >> a >> b && (a || b)) {
            row[b - 1] ^= 1 << (a - 1);
        }

        // GF(2) 上的高斯消元
        int rank = 0;
        for (int col = 0; col < n && rank < n; col++) {
            int pivot = -1;
            for (int i = rank; i < n; i++) {
                if ((row[i] >> col) & 1) {
                    pivot = i;
                    break;
                }
            }
            if (pivot < 0) continue;
            swap(row[rank], row[pivot]);
            for (int i = 0; i < n; i++) {
                if (i != rank && ((row[i] >> col) & 1)) row[i] ^= row[rank];
            }
            rank++;
        }

        bool ok = true;
        for (int i = 0; i < n; i++) {
            if ((row[i] & ((1 << n) - 1)) == 0 && ((row[i] >> n) & 1)) ok = false;
        }
        if (!ok) {
            cout << "Oh,it's impossible~!!\n";
        } else {
            cout << (1LL << (n - rank)) << '\n';  // 自由变元每个取 0/1
        }
    }
    return 0;
}
```

**Python 代码**

```python
import sys


def solve(n, start, target, edges):
    # row[j] 的第 i 位为 1，表示“操作开关 i 会改变开关 j”；第 n 位存常数项
    row = [(1 << j) | (((start[j] ^ target[j]) & 1) << n) for j in range(n)]
    for i, j in edges:
        row[j] ^= 1 << i

    rank = 0
    for col in range(n):                       # GF(2) 上的高斯消元
        pivot = next((i for i in range(rank, n) if (row[i] >> col) & 1), None)
        if pivot is None:
            continue
        row[rank], row[pivot] = row[pivot], row[rank]
        for i in range(n):
            if i != rank and ((row[i] >> col) & 1):
                row[i] ^= row[rank]
        rank += 1

    mask = (1 << n) - 1
    if any((r & mask) == 0 and ((r >> n) & 1) for r in row):
        return "Oh,it's impossible~!!"
    return str(1 << (n - rank))                # 自由变元每个可取 0/1


def main():
    it = iter(sys.stdin.read().split())
    out = []
    for _ in range(int(next(it))):
        n = int(next(it))
        start = [int(next(it)) for _ in range(n)]
        target = [int(next(it)) for _ in range(n)]
        edges = []
        while True:
            a, b = int(next(it)), int(next(it))
            if a == 0 and b == 0:
                break
            edges.append((a - 1, b - 1))       # 操作 a 会改变 b
        out.append(solve(n, start, target, edges))
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

每组数据时间 $O(n^2 + E)$（$E$ 为输入的联动关系条数），空间 $O(n)$。$n < 29$ 时一行方程恰好放得进一个机器字，消元的每步异或都是 $O(1)$。

### 01610 四分树（递归 / 二维前缀和）

http://cs101.openjudge.cn/practice/01610/

**思路**

递归划分矩阵：子矩阵内元素全同则是叶结点，编码为 `0` 加上该取值；否则编码为 `1`，并按**左上、右上、左下、右下**拆成四块继续划分。

整棵树按**宽度优先**顺序把各结点的编码拼成 01 串，再把这个 01 串**当作一个二进制数**输出其十六进制形式——这一步是本题最容易读漏的地方：

- 全 0 的 $2 \times 2$：串为 `00`，作为二进制数是 0，输出 `0`；
- 样例第二组：串为 `100010100`，即 $276 = \texttt{0x114}$，输出 `114`。

判断子矩阵是否全同，用二维前缀和数一下 1 的个数即可 $O(1)$ 完成，避免每个结点都重扫一遍自己的区域。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <array>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int k;
    cin >> k;
    while (k--) {
        int n;
        cin >> n;
        // 逐字符读入，兼容“数字间有无空格”两种数据格式；顺便求二维前缀和
        vector<vector<int>> sum(n + 1, vector<int>(n + 1, 0));
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                char c;
                while (cin.get(c) && c != '0' && c != '1') {
                }
                sum[i][j] = (c - '0') + sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1];
            }
        }
        auto ones = [&](int r, int c, int len) {
            return sum[r + len][c + len] - sum[r][c + len] - sum[r + len][c] + sum[r][c];
        };

        // 宽度优先遍历四分树，内部结点编码为 "1"，叶结点编码为 "0" + 取值
        string bits;
        queue<array<int, 3>> q;                  // {行, 列, 边长}
        q.push({0, 0, n});
        while (!q.empty()) {
            auto [r, c, len] = q.front();
            q.pop();
            int cnt = ones(r, c, len);
            if (cnt == 0 || cnt == len * len) {  // 子矩阵全同，是叶结点
                bits += '0';
                bits += (cnt == 0 ? '0' : '1');
            } else {
                bits += '1';
                int h = len / 2;
                q.push({r, c, h});               // 左上
                q.push({r, c + h, h});           // 右上
                q.push({r + h, c, h});           // 左下
                q.push({r + h, c + h, h});       // 右下
            }
        }

        // 把 01 串当作二进制数，输出其十六进制形式
        bits.insert(bits.begin(), (4 - (int)bits.size() % 4) % 4, '0');
        string hex;
        for (size_t i = 0; i < bits.size(); i += 4) {
            int v = 0;
            for (int j = 0; j < 4; j++) v = v * 2 + (bits[i + j] - '0');
            hex += "0123456789ABCDEF"[v];
        }
        size_t p = hex.find_first_not_of('0');
        cout << (p == string::npos ? "0" : hex.substr(p)) << '\n';
    }
    return 0;
}
```

**Python 代码**

```python
import re
import sys
from collections import deque


def encode(sum2, n):
    def ones(r, c, length):                      # 子矩阵内 1 的个数
        return (sum2[r + length][c + length] - sum2[r][c + length]
                - sum2[r + length][c] + sum2[r][c])

    bits = []
    q = deque([(0, 0, n)])                       # (行, 列, 边长)
    while q:
        r, c, length = q.popleft()
        cnt = ones(r, c, length)
        if cnt == 0 or cnt == length * length:   # 子矩阵全同，是叶结点
            bits.append('00' if cnt == 0 else '01')
        else:                                    # 内部结点：1，再按左上/右上/左下/右下入队
            bits.append('1')
            h = length // 2
            q.append((r, c, h))
            q.append((r, c + h, h))
            q.append((r + h, c, h))
            q.append((r + h, c + h, h))
    return '%X' % int(''.join(bits), 2)          # 01 串视为二进制数，转十六进制


def main():
    data = sys.stdin.read()
    pos = 0

    def next_int():
        nonlocal pos
        m = re.compile(r'\d+').search(data, pos)
        pos = m.end()
        return int(m.group())

    def next_bit():
        nonlocal pos
        while data[pos] not in '01':             # 兼容数字间有无空格
            pos += 1
        pos += 1
        return int(data[pos - 1])

    out = []
    for _ in range(next_int()):
        n = next_int()
        sum2 = [[0] * (n + 1) for _ in range(n + 1)]     # 二维前缀和
        for i in range(1, n + 1):
            row, prev = sum2[i], sum2[i - 1]
            for j in range(1, n + 1):
                row[j] = next_bit() + prev[j] + row[j - 1] - prev[j - 1]
        out.append(encode(sum2, n))
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

时间 $O(n^2)$（前缀和 $O(n^2)$；四分树结点总数也是 $O(n^2)$，每个结点 $O(1)$），空间 $O(n^2)$。若不用前缀和而逐结点重扫，则退化为 $O(n^2 \log n)$。

### 05467 多项式加法（有序映射）

http://cs101.openjudge.cn/practice/05467/

**思路**

每个多项式独占一行，由若干 (系数, 幂次) 整数对组成，**读到幂次为负的整数对就结束该行，且这一对不参与计算**（样例第一组第二行末尾的 `8 -8` 要丢掉）。

用一个按幂次降序的有序映射累加两行的同幂次项，最后跳过系数为 0 的项，按 `[ 系数 幂次 ]` 的格式输出。注意方括号内外都有空格。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <map>
#include <functional>

using namespace std;

// 读入一行多项式，累加到 poly 中；幂次为负的整数对是结束标记，不参与计算
void readPoly(map<int, int, greater<int>> &poly) {
    string line;
    while (getline(cin, line) && line.find_first_not_of(" \t\r") == string::npos) {
    }
    istringstream iss(line);
    int coef, exp;
    while (iss >> coef >> exp) {
        if (exp < 0) break;
        poly[exp] += coef;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string dummy;
    getline(cin, dummy);
    while (n--) {
        map<int, int, greater<int>> poly;   // 幂次降序
        readPoly(poly);
        readPoly(poly);
        bool first = true;
        for (auto [exp, coef] : poly) {
            if (coef == 0) continue;        // 系数为零的项不输出
            if (!first) cout << ' ';
            cout << "[ " << coef << ' ' << exp << " ]";
            first = false;
        }
        cout << '\n';
    }
    return 0;
}
```

### 07207 神奇的幻方（模拟）

http://cs101.openjudge.cn/pctbook/M07207/

**思路**

标准的「罗伯法」构造奇数阶幻方。**最容易错的是阶数**：输入 $N$，要输出的是 $(2N-1) \times (2N-1)$ 的幻方，不是 $N \times N$。

从第一行正中间开始，每次向右上方走；行、列都对阶数取模后，题面中「第一行→最后一行」「最后一列→第一列」两条规则自动满足，只需再单独处理「右上方已有数字（含右上角）则改写到正下方」。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    int m = 2 * n - 1;                       // 幻方阶数
    vector<vector<int>> a(m, vector<int>(m, 0));

    int i = 0, j = m / 2;                    // 第一个数写在第一行正中间
    for (int k = 1; k <= m * m; k++) {
        a[i][j] = k;
        int x = (i - 1 + m) % m, y = (j + 1) % m;   // 右上方
        if (a[x][y] != 0) {
            i = (i + 1) % m;                 // 右上方已有数字则写在正下方
        } else {
            i = x;
            j = y;
        }
    }

    for (const auto &row : a) {
        for (int k = 0; k < m; k++) cout << (k ? " " : "") << row[k];
        cout << '\n';
    }
    return 0;
}
```

### 26978 滑动窗口最大值（单调队列）

http://cs101.openjudge.cn/practice/26978/

**思路**

双端队列里存**下标**，保证对应的值单调递减：

1. 队首下标滑出窗口（$\le i-k$）就弹出；
2. 队尾对应的值不大于新元素时弹出——它既比新元素小又比新元素早出窗口，永无出头之日；
3. 新下标入队；$i \ge k-1$ 时队首就是当前窗口的最大值。

每个下标最多入队、出队各一次。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <deque>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int &x : a) cin >> x;

    deque<int> q;                             // 存下标，对应值单调递减
    bool first = true;
    for (int i = 0; i < n; i++) {
        while (!q.empty() && q.front() <= i - k) q.pop_front();   // 队首滑出窗口
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();   // 队尾比新元素小，永无出头之日
        q.push_back(i);
        if (i >= k - 1) {
            cout << (first ? "" : " ") << a[q.front()];
            first = false;
        }
    }
    cout << '\n';
    return 0;
}
```

**Python 代码**

```python
    ans = []

        while q and q[0] <= i - k:             # 队首滑出窗口

        q.append(i)

            ans.append(a[q[0]])

    main()
```

时间 $O(n)$，空间 $O(k)$。

### 05444 堆栈基本操作（栈模拟）

http://cs101.openjudge.cn/practice/05444/

**思路**

依次读入 $1, 2, \dots, n$ 进栈，每进一个元素可以选择让下一个元素进栈或弹栈，问给定序列能否是栈空时的弹出序列；能则输出整个操作过程，否则输出 `NO`。

贪心模拟即可：为了弹出目标序列的下一个元素 `wanted`，不断把尚未进栈的元素压入，直到栈顶正好是 `wanted`；若 $1..n$ 全部压完栈顶仍不是它，说明 `wanted` 被压在更晚进栈的元素下面（或根本不在 $1..n$ 里），该序列不可能出现。

**两个坑**：

- 输入只有两行，**不是多组数据**；
- 题面提示「给定序列中有可能有不在 $1...n$ 之间的数字」，所以压栈的循环必须用 `next <= n` 兜底，否则遇到越界数字会一直压下去。序列长度和 $n$ 对不上时也直接判 `NO`。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> target;
    for (int x; cin >> x;) target.push_back(x);
    if ((int)target.size() != n) {               // 序列长度对不上，不可能
        cout << "NO\n";
        return 0;
    }

    vector<int> st;
    vector<string> ops;
    int next = 1;                                // 下一个待进栈的元素
    for (int wanted : target) {
        // 不断压栈直到栈顶就是要弹的元素；1..n 全部压完仍不匹配就失败
        while (next <= n && (st.empty() || st.back() != wanted)) {
            st.push_back(next);
            ops.push_back("PUSH " + to_string(next));
            next++;
        }
        if (st.empty() || st.back() != wanted) { // 含越界数字时也会走到这里
            cout << "NO\n";
            return 0;
        }
        st.pop_back();
        ops.push_back("POP " + to_string(wanted));
    }
    for (const string &op : ops) cout << op << '\n';
    return 0;
}
```

### 03882 中缀表达式的值（双栈 / 算符优先）

http://cs101.openjudge.cn/practice/03882/

**思路**

经典的 Dijkstra 双栈法：操作数栈 + 运算符栈。

- 数字：连续读完整个整数后入操作数栈；
- `(`：直接入运算符栈；
- `)`：不断弹栈计算直到遇到 `(`，再弹掉 `(`；
- 四则运算符：当栈顶优先级**不低于**当前运算符时先算栈顶（保证左结合），再把当前运算符入栈；
- 扫描结束后把运算符栈清空。

**两个坑**：第一行是测试数据组数 $N$，不能当成表达式；本题标程用 C++ `int` 生成答案，长表达式会溢出截断，所以 Python 必须用 `to_int32` 在每一步（含解析数字）截断到 32 位有符号范围，除法也要用纯整数的向零取整（`int(a / b)` 会因转 float 丢精度）。详见前面对这道题数据的讨论。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <stack>

using namespace std;

int priority(char op) { return (op == '*' || op == '/') ? 2 : (op == '+' || op == '-') ? 1 : 0; }

int apply(char op, int b, int a) {
    switch (op) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        default: return a / b;                   // C++ 整数除法向零取整
    }
}

int evaluate(const string &expr) {
    stack<int> nums;
    stack<char> ops;
    auto reduce = [&]() {
        char op = ops.top();
        ops.pop();
        int b = nums.top();
        nums.pop();
        int a = nums.top();
        nums.pop();
        nums.push(apply(op, b, a));
    };

    for (size_t i = 0; i < expr.size(); i++) {
        char c = expr[i];
        if (isdigit((unsigned char)c)) {
            int val = 0;
            while (i < expr.size() && isdigit((unsigned char)expr[i])) {
                val = val * 10 + (expr[i] - '0');
                i++;
            }
            i--;
            nums.push(val);
        } else if (c == '(') {
            ops.push(c);
        } else if (c == ')') {
            while (ops.top() != '(') reduce();
            ops.pop();
        } else {
            // 栈顶优先级不低于当前运算符时先算栈顶，保证左结合
            while (!ops.empty() && priority(ops.top()) >= priority(c)) reduce();
            ops.push(c);
        }
    }
    while (!ops.empty()) reduce();
    return nums.top();
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string expr;
    while (n-- && cin >> expr) cout << evaluate(expr) << '\n';
    return 0;
}
```

**Python 代码**

```python
import sys

PRI = {'+': 1, '-': 1, '*': 2, '/': 2, '(': 0}


def to_int32(x):
    """模拟 C++ 32 位有符号整型的溢出截断（本题标程用 int 生成答案）"""
    x &= 0xFFFFFFFF
    return x - 0x100000000 if x >= 0x80000000 else x


def apply(op, b, a):
    if op == '+':
        return to_int32(a + b)
    if op == '-':
        return to_int32(a - b)
    if op == '*':
        return to_int32(a * b)
    q = abs(a) // abs(b)                         # 纯整数向零取整，避免转 float 丢精度
    return to_int32(-q if (a < 0) ^ (b < 0) else q)


def evaluate(expr):
    nums, ops = [], []

    def reduce():
        nums.append(apply(ops.pop(), nums.pop(), nums.pop()))

    i = 0
    while i < len(expr):
        c = expr[i]
        if c.isdigit():
            val = 0
            while i < len(expr) and expr[i].isdigit():
                val = to_int32(val * 10 + int(expr[i]))
                i += 1
            nums.append(val)
            continue
        if c == '(':
            ops.append(c)
        elif c == ')':
            while ops[-1] != '(':
                reduce()
            ops.pop()
        else:
            # 栈顶优先级不低于当前运算符时先算栈顶，保证左结合
            while ops and PRI[ops[-1]] >= PRI[c]:
                reduce()
            ops.append(c)
        i += 1
    while ops:
        reduce()
    return nums[-1]


def main():
    data = sys.stdin.read().split()
```

### 02406 字符串乘方（KMP 前缀函数）

http://cs101.openjudge.cn/practice/02406/

**思路**

求最大的 $n$ 使 $s = a^n$，等价于求最小循环节。用 KMP 的前缀函数 `fail`，令 $k = |s| - \mathrm{fail}[|s|-1]$：

- 若 $|s| \bmod k = 0$，则 $k$ 就是最小循环节长度，答案为 $|s| / k$；
- 否则 $s$ 不是任何真子串的整数次幂，答案为 1。

输入以单独一行 `.` 结束，串长可达 $10^6$，要用快速输入。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    while (cin >> s && s != ".") {
        int n = (int)s.size();
        vector<int> fail(n, 0);                  // KMP 前缀函数
        for (int i = 1, j = 0; i < n; i++) {
            while (j && s[i] != s[j]) j = fail[j - 1];
            if (s[i] == s[j]) j++;
            fail[i] = j;
        }
        int period = n - fail[n - 1];            // 最小循环节长度
        cout << (n % period == 0 ? n / period : 1) << '\n';
    }
    return 0;
}
```

### 05349 合格的字符串（模版匹配）

http://cs101.openjudge.cn/practice/05349/

**思路**

把模版解析成若干「可选字符集合」：`[abc]` 是一个三元素集合，方括号外的普通字符是单元素集合。作业串合格当且仅当它的长度等于集合个数，且每个字符都落在对应集合里。

样例里 `Aab` 能匹配 `a[a2b]b`，说明**匹配是大小写不敏感的**；输出行号（从 1 开始）和**原始字符串**。

**C++ 代码**

```cpp

#include <string>
#include <vector>

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<string> words(n);
    for (string &w : words) cin >> w;
    string pattern;
    cin >> pattern;

    // 把模版拆成若干“可选字符集合”，[abc] 是一个集合，普通字符是单元素集合

            i = j;
        } else {
            slots.push_back(string(1, pattern[i]));

        for (size_t k = 0; ok && k < w.size(); k++) {

                 slots[k].find((char)toupper(w[k])) != string::npos;
        }
        if (ok) cout << i + 1 << ' ' << w << '\n';
    }
    return 0;
}
```

```python
import sys


def parse(pattern):
```

### 05414 由中根序列和后根序列重建二叉树（分治）

http://cs101.openjudge.cn/practice/05414/

**思路**

后根序列的最后一个元素是根，在中根序列中找到它，左边是左子树、右边是右子树，两个序列的对应区间长度相同，于是可以递归切分。

用哈希表把「值 → 中根序列下标」预处理出来，定位根就是 $O(1)$；递归时边访问边输出，得到的就是前根序列。结点是 0～65535 的整数，输出用空格分隔。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>
#include <unordered_map>

using namespace std;

vector<int> inorder, postorder;
unordered_map<int, int> pos;                   // 值 -> 在中根序列中的下标
vector<int> ans;

// 中根序列 [l, r)，其后根序列占 postorder[pl, pl + r - l)
void build(int l, int r, int pl) {
    if (l >= r) return;
    int root = postorder[pl + (r - l) - 1];    // 后根序列的最后一个是根
    int k = pos[root];
    ans.push_back(root);                       // 前根序列：根 -> 左 -> 右
    build(l, k, pl);
    build(k + 1, r, pl + (k - l));
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string line;
    while (getline(cin, line)) {
        istringstream a(line);
        inorder.clear();
        for (int x; a >> x;) inorder.push_back(x);
        if (inorder.empty()) continue;
        if (!getline(cin, line)) break;
        istringstream b(line);
        postorder.clear();
        for (int x; b >> x;) postorder.push_back(x);

        pos.clear();
        for (int i = 0; i < (int)inorder.size(); i++) pos[inorder[i]] = i;
        ans.clear();
        build(0, (int)inorder.size(), 0);
        for (size_t i = 0; i < ans.size(); i++) cout << (i ? " " : "") << ans[i];
        cout << '\n';
    }
    return 0;
}
```

### 05430 表达式·表达式树·表达式求值（表达式树 + 绘图）

http://cs101.openjudge.cn/practice/05430/

**思路**

三步走：

1. **转后缀**：调度场（Shunting-yard）算法，栈顶优先级不低于当前运算符时先出栈；
2. **建树**：扫后缀表达式，字母建叶结点入栈，运算符弹两个结点作为左右孩子（先弹出的是右孩子）；
3. **输出**：后缀串、树形图、求值结果。

树形图的布局按**满二叉树**来算：设树高为 $m$，输出 $2m-1$ 行；把结点按满二叉树编号（根为 1，$i$ 的孩子是 $2i$、$2i+1$），第 $l$ 层第 $p$ 个位置的横坐标为

$$\mathrm{col}(l, p) = 2^{\,m-1-l} \cdot (2p+1)$$

这正好让最底层叶结点落在第 $1, 3, 5, \dots$ 列，父结点落在两个孩子的正中间。父结点左下一格画 `/`、右下一格画 `\`，没有结点的地方留空，**最后要把每行的行末空格去掉**。

求值时除法是整除且**向零取整**，Python 要写 `int(a / b)` 或等价的纯整数写法，不能用 `//`。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <stack>
#include <map>

using namespace std;

struct Node {
    char c;
    Node *left = nullptr, *right = nullptr;
};

int priority(char c) { return (c == '*' || c == '/') ? 2 : 1; }

// 调度场算法：中缀表达式 -> 后缀表达式
string toPostfix(const string &expr) {
    string out;
    stack<char> ops;
    for (char c : expr) {
        if (isalpha((unsigned char)c)) {
            out += c;
        } else if (c == '(') {
            ops.push(c);
        } else if (c == ')') {
            while (ops.top() != '(') {
                out += ops.top();
                ops.pop();
            }
            ops.pop();
        } else {
            while (!ops.empty() && ops.top() != '(' && priority(ops.top()) >= priority(c)) {
                out += ops.top();
                ops.pop();
            }
            ops.push(c);
        }
    }
    while (!ops.empty()) {
        out += ops.top();
        ops.pop();
    }
    return out;
}

Node *build(const string &postfix) {
    vector<Node *> st;
    for (char c : postfix) {
        Node *node = new Node{c};
        if (!isalpha((unsigned char)c)) {
            node->right = st.back();
            st.pop_back();
            node->left = st.back();
            st.pop_back();
        }
        st.push_back(node);
    }
    return st.back();
}

int height(Node *node) { return node ? 1 + max(height(node->left), height(node->right)) : 0; }

int evaluate(Node *node, map<char, int> &val) {
    if (!node->left) return val[node->c];
    int a = evaluate(node->left, val), b = evaluate(node->right, val);
    switch (node->c) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        default: return a / b;   // C++ 整数除法本就向零取整
    }
}

// 按满二叉树布局：第 level 层第 p 个位置的横坐标为 2^(m-1-level) * (2p+1)
void place(Node *node, int idx, int m, vector<string> &grid) {
    int level = 0;
    while ((idx >> (level + 1)) > 0) level++;
    int p = idx - (1 << level);
    int col = (1 << (m - 1 - level)) * (2 * p + 1);
    grid[2 * level][col - 1] = node->c;
    if (node->left) {
        grid[2 * level + 1][col - 2] = '/';
        place(node->left, 2 * idx, m, grid);
    }
    if (node->right) {
        grid[2 * level + 1][col] = '\\';
        place(node->right, 2 * idx + 1, m, grid);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string expr;
    cin >> expr;
    int n;
    cin >> n;
    map<char, int> val;
    for (int i = 0; i < n; i++) {
        char c;
        int x;
        cin >> c >> x;
        val[c] = x;
    }

    string postfix = toPostfix(expr);
    Node *root = build(postfix);
    int m = height(root);
    vector<string> grid(2 * m - 1, string(1 << m, ' '));
    place(root, 1, m, grid);

    cout << postfix << '\n';
    for (string &row : grid) {
        row.erase(row.find_last_not_of(' ') + 1);   // 略去所有行末空格
        cout << row << '\n';
    }
    cout << evaluate(root, val) << '\n';
    return 0;
}
```

**Python 代码**

```python
import sys

PRI = {'+': 1, '-': 1, '*': 2, '/': 2}


def to_postfix(expr):
    """调度场算法：中缀表达式 -> 后缀表达式"""
    out, ops = [], []
    for c in expr:
        if c.isalpha():
            out.append(c)
        elif c == '(':
            ops.append(c)
        elif c == ')':
            while ops[-1] != '(':
                out.append(ops.pop())
            ops.pop()
        else:
            while ops and ops[-1] != '(' and PRI[ops[-1]] >= PRI[c]:
                out.append(ops.pop())
            ops.append(c)
    while ops:
        out.append(ops.pop())
    return ''.join(out)


def build(postfix):
    """由后缀表达式建表达式树，结点表示为 (字符, 左, 右)"""
    st = []
    for c in postfix:
        if c.isalpha():
            st.append((c, None, None))
        else:
            right = st.pop()
            left = st.pop()
            st.append((c, left, right))
    return st[-1]


def height(node):
    return 0 if node is None else 1 + max(height(node[1]), height(node[2]))


def draw(root, m):
    """按满二叉树布局：第 l 层第 p 个位置的横坐标为 2^(m-1-l) * (2p+1)"""
    grid = [[' '] * (2 ** m) for _ in range(2 * m - 1)]
    stack = [(root, 1)]                        # 结点在满二叉树中的编号（根为 1）
    while stack:
        node, idx = stack.pop()
        level = idx.bit_length() - 1
        p = idx - (1 << level)
        col = (1 << (m - 1 - level)) * (2 * p + 1)
        grid[2 * level][col - 1] = node[0]
        if node[1] is not None:
            grid[2 * level + 1][col - 2] = '/'
            stack.append((node[1], 2 * idx))
        if node[2] is not None:
            grid[2 * level + 1][col] = '\\'
            stack.append((node[2], 2 * idx + 1))
    return [''.join(row).rstrip() for row in grid]   # 略去所有行末空格


def evaluate(node, val):
    if node[1] is None:
        return val[node[0]]
    a, b = evaluate(node[1], val), evaluate(node[2], val)
    if node[0] == '+':
        return a + b
    if node[0] == '-':
        return a - b
    if node[0] == '*':
        return a * b
    return int(a / b)                          # 整除，舍弃小数部分（向零取整）


def main():
    data = sys.stdin.read().split('\n')
    expr = data[0].strip()
    n = int(data[1])
    val = {}
    for line in data[2:2 + n]:
        c, x = line.split()
        val[c] = int(x)

    postfix = to_postfix(expr)
    root = build(postfix)
    print(postfix)
    print('\n'.join(draw(root, height(root))))
    print(evaluate(root, val))


if __name__ == '__main__':
    main()
```

**复杂度分析**

设表达式长 $L$、树高 $m$。时间与空间 $O(L + 2^m)$——绘图网格是 $(2m-1) \times 2^m$。$m$ 最坏可达 $O(L)$（如 `a+b+c+d+...` 这样的退化树），但这是题面规定的布局方式，实际数据中 $m$ 很小。

### 03720 文本二叉树（栈 / 树遍历）

http://cs101.openjudge.cn/practice/03720/

**思路**

每行前导 `-` 的个数就是该结点的层次，`*` 表示空结点（占位用，遍历时跳过）。

用一个栈保存当前根到叶的路径：读到层次为 $d$ 的结点时，先把栈截断到长度 $d$，栈中第 $d-1$ 个就是它的父亲；父亲的左孩子还空着就挂左边，否则挂右边——这正好对应题面规则 4、5（有右无左时必有 `*` 占位）。

每棵树输出前序、后序、中序三行，树与树之间空一行。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

struct Node {
    char c;
    int left = -1, right = -1;
};

vector<Node> tree;

enum Order { PRE, POST, IN };

void walk(int u, Order order, string &out) {
    if (u < 0 || tree[u].c == '*') return;       // '*' 是占位的空结点
    if (order == PRE) out += tree[u].c;
    walk(tree[u].left, order, out);
    if (order == IN) out += tree[u].c;
    walk(tree[u].right, order, out);
    if (order == POST) out += tree[u].c;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string line;
    getline(cin, line);
    while (n--) {
        tree.clear();
        vector<int> stack;                       // 当前路径上的结点编号
        int root = -1;
        while (getline(cin, line)) {
            while (!line.empty() && isspace((unsigned char)line.back())) line.pop_back();
            if (line == "0") break;
            int d = 0;
            while (d < (int)line.size() && line[d] == '-') d++;
            int cur = (int)tree.size();
            tree.push_back({line[d]});
            stack.resize(d);
            if (d == 0) {
                root = cur;
            } else {
                Node &parent = tree[stack[d - 1]];
                if (parent.left < 0) {           // 先填左孩子，再填右孩子
                    parent.left = cur;
                } else {
                    parent.right = cur;
                }
            }
            stack.push_back(cur);
        }
        for (Order order : {PRE, POST, IN}) {   // 依次输出前序、后序、中序
            string out;
            walk(root, order, out);
            cout << out << '\n';
        }
        cout << '\n';                            // 两棵树之间以空行分隔
    }
    return 0;
}
```

**Python 代码**

```python
import sys

    """按缩进层次还原二叉树；'*' 表示空结点。返回根结点 (字符, 左, 右)"""
    nodes = []
    for line in lines:
        d = len(line) - len(line.lstrip('-'))
        nodes.append([line[d], None, None, d])   # [值, 左, 右, 层次]
    root = None
    stack = []                                   # 当前路径上的结点
    for node in nodes:
        d = node[3]
        del stack[d:]
        if d == 0:
            root = node
        else:
            parent = stack[d - 1]
            if parent[1] is None:                # 先填左孩子，再填右孩子
                parent[1] = node
            else:
                parent[2] = node
        stack.append(node)

        return
    if order == 'pre':
        out.append(node[0])
    walk(node[1], order, out)
    if order == 'in':
        out.append(node[0])

        out.append(node[0])

            i += 1
        i += 1
        root = build(lines)
        for order in ('pre', 'post', 'in'):
            out = []
            walk(root, order, out)
            res.append(''.join(out))
        res.append('')                           # 两棵树之间以空行分隔
    sys.stdout.write('\n'.join(res) + '\n')


if __name__ == '__main__':
    main()
```

设结点数为 $n$。时间 $O(n)$，空间 $O(n)$。

### 04081 树的转换（左孩子右兄弟）

http://cs101.openjudge.cn/practice/04081/

**思路**

不需要真的把树建出来，一趟扫描即可。

栈中每个结点记录两个量：它**在二叉树中的深度**、以及**已经有几个孩子**。当从结点 $u$ 向下走到它的第 $c$ 个孩子（$c$ 从 0 数起）时，这个孩子在二叉树里的深度是

$$\mathrm{bd}(u) + 1 + c$$

因为第一个孩子挂在 $u$ 的左下（深一层），之后每多一个兄弟就沿右指针再深一层。原树高度就是 `d` / `u` 扫描过程中的最大嵌套深度。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    while (cin >> s) {
        // 栈中每个结点记录：它在二叉树中的深度、已有多少个孩子
        vector<pair<int, int>> stk{{0, 0}};
        int depth = 0, h1 = 0, h2 = 0;
        for (char c : s) {
            if (c == 'd') {
                auto &parent = stk.back();
                // 第一个孩子挂在父结点左下，其后每多一个兄弟就往右下再深一层
                int nd = parent.first + 1 + parent.second;
                parent.second++;
                stk.push_back({nd, 0});
                depth++;
                h1 = max(h1, depth);
                h2 = max(h2, nd);
            } else {
                stk.pop_back();
                depth--;
            }
        }
        cout << h1 << " => " << h2 << '\n';
    }
    return 0;
}
```

**Python 代码**

```python
import sys


def solve(s):
    # 栈中每个结点记录：它在二叉树中的深度、已有多少个孩子
    stack = [[0, 0]]
    depth = h1 = h2 = 0
    for c in s:
        if c == 'd':
            parent = stack[-1]
            # 第一个孩子挂在父结点左下，其后每多一个兄弟就往右下再深一层
            nd = parent[0] + 1 + parent[1]
            parent[1] += 1
            stack.append([nd, 0])
            depth += 1
            h1 = max(h1, depth)
            h2 = max(h2, nd)
        else:
            stack.pop()
            depth -= 1
    return f'{h1} => {h2}'


def main():
    out = [solve(line) for line in sys.stdin.read().split()]
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

时间 $O(|s|)$，空间 $O(h)$（栈深即原树高度，最坏 $O(|s|)$）。

### 01703 发现它，抓住它（种类并查集）

http://cs101.openjudge.cn/practice/01703/

**思路**

经典的「种类并查集」（扩展域并查集）：为每起案件 $x$ 开两个点——$x$ 表示「与 $x$ 同伙」，$x+n$ 表示「与 $x$ 的对立团伙同伙」。

- `D a b`：合并 $(a, b+n)$ 和 $(b, a+n)$；
- `A a b`：$a$ 与 $b$ 同根 → 同一团伙；$a$ 与 $b+n$ 同根 → 不同团伙；否则信息不足。

只用已经读入的信息作答，天然满足题目对时间顺序的要求。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <numeric>

using namespace std;

struct DSU {
    vector<int> parent;

    explicit DSU(int n) : parent(n) { iota(parent.begin(), parent.end(), 0); }

    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }

    void join(int a, int b) { parent[find(a)] = find(b); }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n, m;
        cin >> n >> m;
        // 种类并查集：x 表示“与 x 同伙”，x + n 表示“与 x 不同伙”
        DSU dsu(2 * n + 1);
        while (m--) {
            char op;
            int a, b;
            cin >> op >> a >> b;
            if (op == 'D') {
                dsu.join(a, b + n);
                dsu.join(b, a + n);
            } else if (dsu.find(a) == dsu.find(b)) {
                cout << "In the same gang.\n";
            } else if (dsu.find(a) == dsu.find(b + n)) {
                cout << "In different gangs.\n";
            } else {
                cout << "Not sure yet.\n";
            }
        }
    }
    return 0;
}
```

### 05442 兔子与星空（Prim 最小生成树）

http://cs101.openjudge.cn/practice/05442/

**思路**

**输入格式是本题的主要难点**：只有 $n-1$ 行（最后一个字母开头的行不给），每行形如「起点字母 $k$ 终点字母 权值 终点字母 权值 …」，$k$ 是这一行给出的边数，且只连向字母表中**靠后**的星星。按 token 读入即可，不要按「$n(n-1)/2$ 条边」去读。

建图后跑最小生成树。$n \le 26$，用邻接矩阵版 Prim 最直接；也可以用堆优化的 Prim 或 Kruskal。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <climits>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<vector<int>> w(n, vector<int>(n, INT_MAX));
    for (int i = 0; i < n - 1; i++) {            // 只给出前 n-1 个字母开头的行
        string name;
        int k;
        cin >> name >> k;
        int u = name[0] - 'A';
        while (k--) {
            string other;
            int c;
            cin >> other >> c;
            int v = other[0] - 'A';
            w[u][v] = w[v][u] = min(w[u][v], c);
        }
    }

    // Prim 算法：每次把离当前生成树最近的点并入
    vector<int> dist(n, INT_MAX);
    vector<bool> used(n, false);
    dist[0] = 0;
    long long total = 0;
    for (int step = 0; step < n; step++) {
        int u = -1;
        for (int i = 0; i < n; i++) {
            if (!used[i] && (u < 0 || dist[i] < dist[u])) u = i;
        }
        used[u] = true;
        total += dist[u];
        for (int v = 0; v < n; v++) {
            if (!used[v] && w[u][v] < dist[v]) dist[v] = w[u][v];
        }
    }
    cout << total << '\n';
    return 0;
}
```

**Python 代码**

```python
import sys
import heapq


def main():
    it = iter(sys.stdin.read().split())
    n = int(next(it))
    g = [[] for _ in range(n)]
    for _ in range(n - 1):                       # 只给出前 n-1 个字母开头的行
        u = ord(next(it)) - 65
        for _ in range(int(next(it))):
            v = ord(next(it)) - 65
            c = int(next(it))
            g[u].append((c, v))
            g[v].append((c, u))

    # Prim 算法（堆优化）：每次把离当前生成树最近的点并入
    heap = [(0, 0)]
    visited = [False] * n
    total = 0
    while heap:
        c, u = heapq.heappop(heap)
        if visited[u]:
            continue
        visited[u] = True
        total += c
        for e in g[u]:
            if not visited[e[1]]:
                heapq.heappush(heap, e)
    print(total)


if __name__ == '__main__':
    main()
```

**复杂度分析**

邻接矩阵版 Prim：时间 $O(V^2)$，空间 $O(V^2)$；堆优化版：时间 $O(E \log E)$，空间 $O(V+E)$。本题 $V \le 26$、$E \le 75$。

### 05443 兔子与樱花（Dijkstra 最短路 + 路径还原）

http://cs101.openjudge.cn/practice/05443/

**思路**

**这是最短路径问题，不是最小生成树**——题目问的是两点之间怎么走最短，要输出整条路线。

地点是字符串，先映射成编号。每次询问跑一次 Dijkstra，记录前驱数组，从终点回溯出路径，按 `A->(w)->B->(w)->C` 输出，其中 $w$ 是相邻两点的 `dist` 之差。起点等于终点时只输出地名本身（回溯得到的路径只有一个点，自然满足）。

$P < 30$、$R < 20$，每次查询重跑一遍 Dijkstra 完全够用；也可以直接上 Floyd-Warshall 一次算完所有点对。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <map>
#include <queue>
#include <climits>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int p;
    cin >> p;
    map<string, int> id;
    vector<string> name(p);
    for (int i = 0; i < p; i++) {
        cin >> name[i];
        id[name[i]] = i;
    }

    vector<vector<pair<int, int>>> g(p);         // (邻点, 距离)
    int q;
    cin >> q;
    while (q--) {
        string a, b;
        int d;
        cin >> a >> b >> d;
        g[id[a]].push_back({id[b], d});
        g[id[b]].push_back({id[a], d});
    }

    int r;
    cin >> r;
    while (r--) {
        string a, b;
        cin >> a >> b;
        int s = id[a], t = id[b];

        // Dijkstra，同时记录前驱以便还原路径
        vector<int> dist(p, INT_MAX), prev(p, -1);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
        dist[s] = 0;
        pq.push({0, s});
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d > dist[u]) continue;
            if (u == t) break;
            for (auto [v, c] : g[u]) {
                if (d + c < dist[v]) {
                    dist[v] = d + c;
                    prev[v] = u;
                    pq.push({dist[v], v});
                }
            }
        }

        vector<int> path;
        for (int u = t; u != -1; u = prev[u]) path.push_back(u);
        cout << name[path.back()];
        for (int i = (int)path.size() - 2; i >= 0; i--) {
            cout << "->(" << dist[path[i]] - dist[path[i + 1]] << ")->" << name[path[i]];
        }
        cout << '\n';
    }
    return 0;
}
```

**Python 代码**

```python
import sys
import heapq


def main():
    data = sys.stdin.read().split()
    pos = 0

    def take(k=1):
        nonlocal pos
        pos += k
        return data[pos - k:pos]

    p = int(take()[0])
    names = take(p)
    id = {w: i for i, w in enumerate(names)}
    g = [[] for _ in range(p)]                   # (邻点, 距离)
    for _ in range(int(take()[0])):
        a, b, d = take(3)
        g[id[a]].append((id[b], int(d)))
        g[id[b]].append((id[a], int(d)))

    out = []
    for _ in range(int(take()[0])):
        a, b = take(2)
        s, t = id[a], id[b]

        # Dijkstra，同时记录前驱以便还原路径
        dist = [float('inf')] * p
        prev = [-1] * p
        dist[s] = 0
        heap = [(0, s)]
        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:
                continue
            if u == t:
                break
            for v, c in g[u]:
                if d + c < dist[v]:
                    dist[v] = d + c
                    prev[v] = u
                    heapq.heappush(heap, (dist[v], v))

        path = []
        u = t
        while u != -1:
            path.append(u)
            u = prev[u]
        path.reverse()
        line = names[path[0]]
        for x, y in zip(path, path[1:]):
            line += f'->({dist[y] - dist[x]})->{names[y]}'
        out.append(line)
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

每次查询 $O((V+E)\log V)$，共 $R$ 次，总时间 $O(R\,(V+E)\log V)$，空间 $O(V+E)$。Floyd-Warshall 版本为 $O(V^3)$ 预处理 + 每次 $O(V)$ 还原路径。

### 04084 拓扑排序（Kahn 算法 + 小根堆）

http://cs101.openjudge.cn/practice/04084/

**思路**

统计入度，把入度为 0 的顶点放进**小根堆**（不是普通队列），每次取编号最小的输出，再把它的后继入度减 1、减到 0 就入堆——这样才能满足「同等条件下编号小的顶点在前」。

注意输出格式：顶点从 1 开始编号，且要带 `v` 前缀，如 `v1 v3 v2 v6 v4 v5`。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int v, a;
    cin >> v >> a;
    vector<vector<int>> g(v + 1);
    vector<int> indeg(v + 1, 0);
    while (a--) {
        int x, y;
        cin >> x >> y;
        g[x].push_back(y);
        indeg[y]++;
    }

    // Kahn 算法；用小根堆保证同等条件下编号小的顶点在前
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int i = 1; i <= v; i++) {
        if (indeg[i] == 0) pq.push(i);
    }
    bool first = true;
    while (!pq.empty()) {
        int u = pq.top();
        pq.pop();
        cout << (first ? "" : " ") << 'v' << u;
        first = false;
        for (int w : g[u]) {
            if (--indeg[w] == 0) pq.push(w);
        }
    }
    cout << '\n';
    return 0;
}
```

**Python 代码**

```python
        g[x].append(y)
        indeg[y] += 1

    # Kahn 算法；用小根堆保证同等条件下编号小的顶点在前
    heap = [i for i in range(1, v + 1) if indeg[i] == 0]

    while heap:
        u = heapq.heappop(heap)
        order.append(f'v{u}')

    print(' '.join(order))
```

### 29458 求逆序对数（归并分治）

http://cs101.openjudge.cn/practice/29458/

**思路**

归并排序的副产品。归并时若右半的 `a[j]` 先被取出，说明左半剩下的 `mid - i` 个元素都比它大，一次性累加这么多逆序对。

$n \le 2 \times 10^5$、答案最大约 $2 \times 10^{10}$，C++ 要用 `long long`。

**C++ 代码**

```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<int> a, buf;

// 归并排序，顺带统计跨越左右两半的逆序对
long long mergeSort(int l, int r) {
    if (r - l < 2) return 0;
    int mid = (l + r) / 2;
    long long cnt = mergeSort(l, mid) + mergeSort(mid, r);
    int i = l, j = mid, k = l;
    while (i < mid || j < r) {
        if (j == r || (i < mid && a[i] <= a[j])) {
            buf[k++] = a[i++];
        } else {
            cnt += mid - i;                      // a[i..mid) 都比 a[j] 大
            buf[k++] = a[j++];
        }
    }
    copy(buf.begin() + l, buf.begin() + r, a.begin() + l);
    return cnt;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    a.resize(n);
    buf.resize(n);
    for (int &x : a) cin >> x;
    cout << mergeSort(0, n) << '\n';
    return 0;
}
```

**Python 代码**

```python
import sys


def merge_sort(a):
    """归并排序，返回 (有序数组, 逆序对数)"""
    if len(a) < 2:
        return a, 0
    mid = len(a) // 2
    left, c1 = merge_sort(a[:mid])
    right, c2 = merge_sort(a[mid:])
    merged = []
    i = j = cnt = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            cnt += len(left) - i                 # left[i:] 都比 right[j] 大
            merged.append(right[j])
            j += 1
    merged += left[i:]
    merged += right[j:]
    return merged, cnt + c1 + c2


def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    print(merge_sort(a)[1])


if __name__ == '__main__':
    main()
```

**复杂度分析**

时间 $O(n \log n)$，空间 $O(n)$。

### 03702 距离排序（稳定排序）

http://cs101.openjudge.cn/practice/03702/

**思路**

按 $i < j$ 的顺序枚举所有点对，这个枚举顺序就是题面说的「输入数据中靠前的点对」的顺序，且保证了每行里前一个点在输入中确实更靠前。

按距离**降序**排序，距离相同时要保持枚举顺序，所以必须用**稳定排序**；比较时用整数的平方距离，避免开方带来的浮点误差导致相等的距离被判成不等。输出保留两位小数。

**C++ 代码**

```cpp
#include <iostream>
#include <iomanip>
#include <vector>
#include <cmath>
#include <algorithm>
#include <array>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<array<int, 3>> p(n);
    for (auto &q : p) cin >> q[0] >> q[1] >> q[2];

    // 枚举 i < j，距离用整数平方比较以避免浮点误差
    struct Pair {
        int i, j, d2;
    };
    vector<Pair> pairs;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int dx = p[i][0] - p[j][0], dy = p[i][1] - p[j][1], dz = p[i][2] - p[j][2];
            pairs.push_back({i, j, dx * dx + dy * dy + dz * dz});
        }
    }
    // 稳定排序：距离相同时，保持输入中靠前的点对在前
    stable_sort(pairs.begin(), pairs.end(),
                [](const Pair &a, const Pair &b) { return a.d2 > b.d2; });

    cout << fixed << setprecision(2);
    for (const Pair &e : pairs) {
        cout << '(' << p[e.i][0] << ',' << p[e.i][1] << ',' << p[e.i][2] << ")-("
             << p[e.j][0] << ',' << p[e.j][1] << ',' << p[e.j][2] << ")="
             << sqrt((double)e.d2) << '\n';
    }
    return 0;
}
```

**Python 代码**

```python
import sys
from math import sqrt


def main():
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    pts = [tuple(data[1 + 3 * i: 4 + 3 * i]) for i in range(n)]

    # 枚举 i < j，距离用整数平方比较以避免浮点误差
    pairs = []
    for i in range(n):
        for j in range(i + 1, n):
            d2 = sum((a - b) ** 2 for a, b in zip(pts[i], pts[j]))
            pairs.append((d2, i, j))
    # sorted 是稳定排序：距离相同时，保持输入中靠前的点对在前
    pairs.sort(key=lambda e: -e[0])

    out = []
    for d2, i, j in pairs:
        a = '(%d,%d,%d)' % pts[i]
        b = '(%d,%d,%d)' % pts[j]
        out.append(f'{a}-{b}={sqrt(d2):.2f}')
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

设点数为 $n$，点对数 $\binom{n}{2}$。时间 $O(n^2 \log n)$，空间 $O(n^2)$。本题 $n \le 10$。

### 01002 方便记忆的电话号码（哈希与排序）

http://cs101.openjudge.cn/pctbook/M01002/

**思路**

**字母映射表里 Q 和 Z 是不出现的**，所以不能简单地按 A～Z 每三个一组去排：`P,R,S -> 7`、`W,X,Y -> 9`。代码里在 Q、Z 的位置放占位符以保证下标对齐。

去掉所有 `-`，把字母换成数字得到 7 位号码，在第 3 位后插入 `-` 得到标准格式，用映射计数。输出按标准号码升序、只输出出现次数 $\ge 2$ 的；一个重复都没有时输出 `No duplicates.`。

**C++ 代码**

```cpp
#include <iostream>
#include <string>
#include <map>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // A,B,C->2  D,E,F->3  G,H,I->4  J,K,L->5  M,N,O->6  P,R,S->7  T,U,V->8  W,X,Y->9
    // Q 与 Z 不出现，用 '?' 占位保证下标对齐
    const string table = "2223334445556667?77888999?";

    int n;
    cin >> n;
    map<string, int> count;
    while (n--) {
        string s, digits;
        cin >> s;
        for (char c : s) {
            if (isdigit((unsigned char)c)) {
                digits += c;
            } else if (isalpha((unsigned char)c)) {
                digits += table[toupper(c) - 'A'];
            }
        }
        digits.insert(3, "-");                   // 标准格式 xxx-xxxx
        count[digits]++;
    }

    bool found = false;
    for (auto &[number, c] : count) {            // map 已按标准号码升序
        if (c >= 2) {
            cout << number << ' ' << c << '\n';
            found = true;
        }
    }
    if (!found) cout << "No duplicates.\n";
    return 0;
}
```

**Python 代码**

```python
import sys
from collections import Counter

# A,B,C->2  D,E,F->3  G,H,I->4  J,K,L->5  M,N,O->6  P,R,S->7  T,U,V->8  W,X,Y->9
# Q 与 Z 不出现，用 '?' 占位保证下标对齐
TABLE = str.maketrans('ABCDEFGHIJKLMNOPQRSTUVWXYZ', '2223334445556667?77888999?')


def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    count = Counter()
    for s in data[1:1 + n]:
        digits = s.upper().replace('-', '').translate(TABLE)
        count[digits[:3] + '-' + digits[3:]] += 1   # 标准格式 xxx-xxxx

    out = [f'{number} {c}' for number, c in sorted(count.items()) if c >= 2]
    sys.stdout.write('\n'.join(out) + '\n' if out else 'No duplicates.\n')


if __name__ == '__main__':
    main()
```

**复杂度分析**

设 $n$ 个号码、串长 $L$、不同号码 $K$ 个。时间 $O(n \cdot L + K \log K)$，空间 $O(K)$。
