# 第七章作业

### 1 图的存储结构与周游

有向图 `G` 的顶点为 `v0` 至 `v5`，边集如下（`<u, v>` 表示从 `u` 指向 `v` 的有向边）：

```text
<0,1>  <0,3>  <1,2>  <1,4>  <2,5>  <3,4>  <4,2>  <4,5>  <5,0>
```

请完成下列问题：

1. 写出 `G` 的相邻矩阵，并计算每个顶点的入度和出度。
2. 画出 `G` 的邻接表（每个顶点的边表按终点编号从小到大排列）。
3. 从 `v0` 出发，按"编号小的邻接点先访问"的规则，写出深度优先周游（DFS）序列和广度优先周游（BFS）序列。
4. 深度优先周游中，若从当前顶点遇到一条指向"已访问但尚未退出递归"的顶点的边，就说明图中存在回路。指出本图 DFS 过程中出现的这样的边，并说明理由。
5. 设每个指针占 4 字节、顶点编号占 2 字节、相邻矩阵的每个元素占 1 字节。分别计算本图用相邻矩阵和邻接表（顶点表只存表头指针，边结点存终点编号和 `next` 指针）所需的字节数；并对一般的 `n` 个顶点、`e` 条边的有向图，给出邻接表比相邻矩阵更省空间的条件。

> 第 (4) 问"用 DFS 判断有向图是否有回路"对应编程题：力扣 207. 课程表。

### 2 项目依赖、拓扑排序与关键路径

某实验项目包含 `A` 至 `H` 共 8 项任务。一项任务的全部前驱任务完成后，它才能开始。依赖关系为：

```text
A -> D
B -> C, D
C -> E
D -> E
E -> F
F -> G
G -> H
```

各任务持续时间如下表所示：

| 任务 | A | B | C | D | E | F | G | H |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 持续时间 | 3 | 2 | 4 | 3 | 5 | 2 | 3 | 1 |

请完成下列问题：

1. 用顶点集与边集的形式表示该有向图。
2. 写出基于入度的拓扑排序伪代码（教材 7.4.3 节，用队列保存入度为 0 的顶点），并给出一个合法的拓扑序列。
3. 假设互不依赖的任务可以并行进行，求完成全部任务的最短总时间，并写出所有关键路径（总时间由其决定、任何一项任务延误都会推迟整个项目的路径）。

### 3 最小生成树与次小生成树

给定无向加权图，顶点集 $V = \{A, B, C, D, E, F, G\}$，边及权值如下：

| 边 | 权值 |
|---|---:|
| A-B | 2 |
| A-C | 5 |
| B-C | 3 |
| B-D | 4 |
| C-D | 6 |
| C-E | 2 |
| D-E | 5 |
| D-F | 7 |
| E-F | 4 |
| E-G | 6 |
| F-G | 3 |
| D-G | 8 |

请完成下列问题：

1. 使用 Kruskal 算法求一棵最小生成树，按选入次序写出各边（权值相同时按上表次序扫描），并写出总权值。
2. 使用 Prim 算法从顶点 `A` 出发求最小生成树，按加入次序写出各边（候选边权值相同时按上表次序选取）。两种算法得到的生成树是否相同？
3. 求该图的次小生成树（总权值严格大于最小生成树总权值的最轻生成树），说明思路并给出伪代码。

> 最小生成树对应编程题：力扣 1584. 连接所有点的最小费用、OpenJudge 05442 兔子与星空。第 (3) 问的"换边"思路对应力扣 1489. 找到最小生成树里的关键边和伪关键边。

### 4 单源最短路径

给定带权有向图 $G = (V, E)$，顶点集 $V = \{A, B, C, D, E, F\}$，边及权值如下（`A-B` 表示从 `A` 指向 `B` 的有向边）：

| 边 | 权值 |
|---|---:|
| A-B | 7 |
| A-C | 2 |
| A-D | 9 |
| C-B | 3 |
| C-D | 4 |
| C-E | 8 |
| B-D | 2 |
| B-E | 5 |
| D-E | 1 |
| D-F | 6 |
| E-F | 2 |

请完成下列问题：

1. 以 `A` 为源点，使用 Dijkstra 算法求 `A` 到其余各顶点的最短路径长度。请写出每一轮选定的顶点及距离数组的变化，并给出每个顶点对应的一条最短路径。
2. 给出 Dijkstra 算法的伪代码。
3. Dijkstra 算法要求边权非负。请构造一个只有 3 个顶点、含一条负权边但不含负权回路的有向图，使该算法从源点出发得到错误的最短路径长度，并指出算法在哪一步出错。
