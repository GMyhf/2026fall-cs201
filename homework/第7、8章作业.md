### 题目一 项目依赖、拓扑排序与关键路径

某实验项目包含 A 至 H 共 8 项任务。任务完成后，后继任务才能开始。依赖关系为：

\[
A -> D；B -> C、D；C -> E；D -> E；E -> F；F -> G；G -> H
\]

各任务持续时间如下表所示：

| 任务 | A | B | C | D | E | F | G | H |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 持续时间 | 3 | 2 | 4 | 3 | 5 | 2 | 3 | 1 |

请完成：

1. 用顶点集与边集的形式表示该有向图；
2. 写出基于入度的拓扑排序伪代码，并给出一个合法的拓扑序列；
3. 计算完成全部任务的最短总时间，并写出所有关键路径。

### 题目二 最小生成树与次小生成树

给定无向加权图，顶点集 \(V = \{A,B,C,D,E,F,G\}\)，边及权值如下：

| 边 | 权值 |
|---|---:|
| A-B | 2 |
| A-C | 5 |
| B-C | 3 |
| B-D | 4 |
| C-D | 6 |
| C-E | 2 |
| D-E | 5 |
| D-F | 7 |
| E-F | 4 |
| E-G | 6 |
| F-G | 3 |
| D-G | 8 |

请完成：

1. 使用 Kruskal 算法求一棵最小生成树，按选入次序写出各边；
2. 写出该最小生成树的总权值；
3. 求该图的次小生成树（总权值严格大于最小生成树总权值的最轻生成树），说明思路并给出伪代码。

### 题目三 单源最短路径

给定带权有向图 G=(V,E)，顶点集 V=\{A,B,C,D,E,F\}，边及权值如下：

| 边 | 权值 |
|---|---:|
| A-B | 7 |
| A-C | 2 |
| A-D | 9 |
| C-B | 3 |
| C-D | 4 |
| C-E | 8 |
| B-D | 2 |
| B-E | 5 |
| D-E | 1 |
| D-F | 6 |
| E-F | 2 |

以 A 为源点，使用 Dijkstra 算法求 A 到其余各顶点的最短路径长度。请写出每一轮选定的顶点及距离数组的变化，并给出算法伪代码。

### 题目四 快速排序的分割

对序列

\[
43,18,65,27,52,9,34,71,26,60,15,40
\]

进行快速排序的第一轮分割。采用 Lomuto 分割法：最后一个元素为 pivot，从小到大排序。请写出每一次实际交换后的序列状态，并给出 pivot 的最终位置。

### 题目五 MSD 与 LSD 基数排序

将下列记录按关键字从小到大排序。所有关键字均按两位十进制数处理；42a 与 42b 是关键字相同但彼此不同的记录。

\[
42a,17,58,06,93,42b,71,25,80,13,65,31
\]

1. 用 MSD 基数排序：先按十位分桶，再对每个含多个记录的桶按个位递归分桶。请列出每一趟各非空桶中的记录顺序，不必做全局收集。
2. 用 LSD 基数排序：先按个位、再按十位。请给出每一趟分桶后的收集结果。
